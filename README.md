# kurongeka.com

Your business, properly set up. Kurongeka launches small businesses online (website, brand, payments, bookings) at fixed prices in GBP, then keeps them running. By Kapture.

- Astro 7 + TypeScript on Vercel, Wix Headless backend (the kurongeka.com Wix site).
- Content, prices and leads are managed in the Wix Dashboard.

```bash
npm install
npm run dev      # http://localhost:4321
npm run verify   # types, unit tests, production build
```

See `CLAUDE.md` for architecture and conventions, `docs/strategy.md` for the business, and `docs/estate.md` for the audit and clean-up plan.
