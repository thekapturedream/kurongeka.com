# kurongeka.com

Your business, properly set up. Kurongeka launches small businesses online (website, brand, payments, bookings) at fixed prices in GBP, then keeps them running. Run from the UK by Kapture.

- Astro 7 + TypeScript on Vercel, Wix Headless backend (the kurongeka.com Wix site).
- Wix is the back office: content, prices, leads, client accounts and projects are managed in the Wix Dashboard.
- Custom apps: the Kurongeka Check, free tools (website check, name and domain check, brand colours, email signature), contact and call requests, directory applications, and the client portal.

```bash
npm install
npm run dev        # http://localhost:4321
npm run verify     # types, unit tests, production build
npm run test:e2e   # browser tests, desktop and mobile
```

See `CLAUDE.md` for architecture, conventions and deployment, `docs/strategy.md` for the business, and `docs/estate.md` for the audit and clean-up plan.
